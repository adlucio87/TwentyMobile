OAuth 2.0 PKCE iOS Android
How do I configure Google / SSO (OAuth 2.0 PKCE) with Twenty CRM?

TwentyMobile signs in through Twenty CRM's native OAuth 2.0 authorization-code flow using PKCE (RFC 7636) opened in the system browser.

✨ Zero-Touch Automatic Setup (Twenty Cloud & Supported Instances):
If your Twenty CRM instance supports Dynamic Client Registration (RFC 7591) — standard on Twenty Cloud (twenty.com) — TwentyMobile registers the application automatically in the background! The Client ID is generated, securely saved, and pre-filled with zero manual configuration. You can skip the manual steps below and sign in immediately.

Manual Setup (Fallback for Self-Hosted Instances):
If your self-hosted instance does not have dynamic registration enabled, configure your application manually in 4 easy steps:

  1. Open Twenty CRM in your browser: Log into your instance and go to Settings → Applications.
  2. Create a new Application: Click Create Application (or New Application) and enter a name (e.g. "TwentyMobile").
  3. Register the Redirect URI: Copy the exact Redirect URI displayed in TwentyMobile's OAuth screen and paste it into the application settings on Twenty CRM:
Instance Setup Redirect URI to Register
Single-workspace (default self-hosted) https://<your-instance>/auth/oauth-propagator/callback
Multi-workspace / Custom Cloud https://twentymobilecrm.luciosoft.it/oauth/callback
One-Tap Copy: You do not need to guess the URI: TwentyMobile automatically queries your instance capabilities and displays the exact Redirect URI to register with a one-tap copy button right on screen.
  1. Obtain the Client ID: Save the application on Twenty CRM and copy the generated Client ID (and Client Secret, if issued).
  2. Sign in from TwentyMobile: Paste the Client ID into TwentyMobile and tap Sign in with Browser. Authorize with your Google or SSO account: the system browser safely redirects back into the app using the registered pocketcrm://oauth/callback scheme.
First-Time Login Note (Landing on Twenty Dashboard):
If your browser is not already logged in to Twenty CRM, authenticating will take you to your workspace dashboard first. Do not close the browser. Simply tap your browser's Back (Indietro) button on Android (or edge-swipe / tap Cancel and reopen on iOS): Twenty CRM will detect your active session and present the "Connect TwentyMobile to your account" consent prompt. Click Authorize to finalize and return to the app!
OAuth Troubleshooting iOS Android
Why does the browser land on my Twenty dashboard instead of redirecting back to the app?

When authenticating through the system browser for the first time without an existing browser session, Twenty CRM's Single Page Application (SPA) routes successful logins to the workspace dashboard instead of remembering the initial authorization prompt.

How to complete authorization in 2 seconds:
  1. Do not close or panic when you see your workspace dashboard.
  2. Navigate back to the authorization prompt:
    • On Android: Tap the browser's Back (Indietro) button or use the back gesture.
    • On iOS: Swipe from the left edge of the screen to the right to go back, or tap Cancel and tap Sign in with Browser again. Since Safari now retains your login session, Twenty CRM will open directly to the consent screen!
  3. Twenty CRM will recognize your authenticated session and display the consent modal: "Connect TwentyMobile to your account".
  4. Click Authorize: the browser will immediately trigger the callback and return you to TwentyMobile logged in!

Note: Once your browser has authenticated your session, subsequent logins or token refreshes will detect your session immediately and display the consent prompt directly without landing on the dashboard.

OAuth & Applications
Why do I see multiple "TwentyMobile" applications in Twenty CRM Settings?

TwentyMobile supports RFC 7591 Dynamic Client Registration. When connecting to a supported instance (like Twenty Cloud), the app registers itself automatically with the CRM and securely stores its assigned Client ID on your device.

When you uninstall and reinstall TwentyMobile:

  1. Your device's operating system (iOS or Android) completely wipes the app's local secure storage, including the previous Client ID.
  2. On the fresh install, TwentyMobile detects no local credentials and automatically requests a new registration from Twenty CRM.
  3. Twenty CRM registers the new install with its own unique Client ID, resulting in a new "TwentyMobile" entry in Settings → Applications.
Safe to Clean Up: Only the newest application entry is used by your active install. Older entries from previous installations can be safely deleted in Twenty CRM under Settings → Applications at any time.
Email & Password 2FA & OTP
Can I log in with standard Email and Password? Does it support 2FA and Captchas?

Yes, absolutely. Standard credentials login is fully supported for all workspace members and administrators.

  • Two-Factor Authentication (2FA / OTP): If your Twenty account has 2FA enabled, TwentyMobile automatically detects the pending challenge and opens a dedicated 6-digit OTP verification screen with smart clipboard pasting.
  • Automated Captcha Solving: If your Twenty CRM instance enforces Cloudflare Turnstile or Google reCAPTCHA, TwentyMobile resolves the verification challenge invisibly in the background so you never get blocked by security checks.
  • Workflow Execution: Logging in with Email & Password provides a user-scoped JWT token, which is required if you plan to execute Twenty manual workflows.
API Key Developers
How do I connect using a Twenty CRM API Key?

API Key authentication is ideal for quick administrator access or developer environments:

  1. In Twenty CRM, navigate to Settings → Developers → API Keys.
  2. Click Create API Key, assign your desired permissions (e.g. read/write access), and copy the secret token.
  3. In TwentyMobile, select Login with API Key and paste the key.
Upstream Workflow Limitation: Twenty CRM's GraphQL API restricts executing manual workflows when authenticated via an API Key (returns 403 Forbidden). For manual workflow triggers, use Email & Password or Google SSO login.
iOS 18+ Exclusive Apple Contacts
[iOS 18+] How do I display Twenty CRM people in the native Apple Contacts app?

TwentyMobile supports Apple's native Contacts Provider API introduced in iOS 18:

  1. Open TwentyMobile and go to Settings → iOS Contacts.
  2. Toggle on "Show Twenty people in iOS Contacts".
  3. Open the native Apple Contacts app on your iPhone or iPad: you will see a live, dedicated container named Twenty.
No iCloud Pollution: CRM contacts remain strictly in the live Twenty container. They are not merged into your personal iCloud address book. Disabling the toggle or logging out of TwentyMobile cleanly removes the container without leaving duplicate contacts behind.
Security iOS Android
[iOS & Android] Why does TwentyMobile use the system browser instead of an in-app WebView for SSO?

Embedded in-app WebViews present serious security concerns for federated login:

  • Protection Against Credential Sniffing: Embedded webviews allow host applications to inspect entered passwords and cookies. Major identity providers (including Google) intentionally block logins from generic WebViews with errors like disallowed_useragent.
  • Native Platform Security: TwentyMobile uses Chrome Custom Tabs on Android and ASWebAuthenticationSession on iOS. Your credentials are typed strictly into Google or your SSO provider.
  • Ephemeral Isolation: Authentication sessions run with ephemeral flags, guaranteeing that shared or corporate devices never leak cookies or inherit previous users' accounts.
Offline OCR iOS Android
How does the Business Card Scanner work? Does it send photos to external AI servers?

The Business Card Scanner lets you capture new leads on the go in seconds:

  1. From the Contacts screen, tap the Scan Card button.
  2. Capture a photo of the card with your camera, or pick an existing image from your photo album.
  3. The on-device OCR engine parses full names, company, email addresses, phone numbers, and websites with smart heuristics.
  4. Review and edit any extracted fields, then tap save: TwentyMobile creates the contact in Twenty CRM immediately with optimistic UI updates.
100% Offline & Private: OCR text recognition runs entirely on your smartphone's hardware. Your card photos and contact details are never sent to third-party AI APIs or external OCR cloud services.
Local Notifications iOS Android
How do task reminders and notifications work on iOS and Android?

TwentyMobile schedules local push notifications directly on your phone so you never miss an important customer follow-up:

  • Schedule Timing: Tasks with scheduled due dates trigger a notification 30 minutes before the deadline as well as at the exact due time.
  • Android Setup: Android aggressive power management (Doze mode) can delay alarms. For instant reminders, navigate to Settings → Apps → TwentyMobile → Battery and set it to "Unrestricted".
  • iOS Setup: Ensure you accept the notification permission prompt during onboarding, or verify under iOS Settings → TwentyMobile → Notifications.
vCard (.vcf) Sharing
Can I export contacts or share them with colleagues via vCard (.vcf)?

Yes. From any Contact Detail view, tap the Share action in the top AppBar.

TwentyMobile generates a standard RFC vCard file containing the contact's full name, linked company, emails, phone numbers, and address. You can send it instantly via AirDrop, WhatsApp, Telegram, email, or import it into your personal address book.

Workflows Troubleshooting
Why do I receive a 403 Forbidden error when triggering a manual workflow?

In Twenty CRM, the backend GraphQL mutation for triggering manual workflows requires a verified User Identity (JWT token).

  • If you logged in using an API Key, Twenty CRM's server treats the connection as an automated system key and returns FORBIDDEN (403) when attempting to run user workflows.
  • How to fix: Log out and reconnect using your Email & Password or Google / SSO. This establishes a full user session and enables the interactive Slide-to-Execute workflow button.
Dynamic Objects GraphQL
Does TwentyMobile support custom dynamic objects and custom fields created in Twenty?

Yes, with full schema introspection! TwentyMobile dynamically queries your Twenty CRM metadata schema over GraphQL.

  • Standard & Custom Objects: In addition to Contacts, Companies, and Tasks, all custom workspace entities (such as Opportunities or custom tables) appear in the More tab.
  • Customizable Layout: Tap the ⚙ settings icon on any dynamic object detail view to toggle field visibility and adjust display order. Your preferences are persisted securely on your phone.
  • Composite Fields: Full support for complex data types including Currency, Address, Phone, and Relation Pickers (linking companies and contacts).
100% Self-Hosted Zero Tracking
Is any customer data or telemetry routed through Luciosoft servers?

No, zero CRM data, customer records, or credentials are ever collected or intermediated.

TwentyMobile connects directly from your mobile device to your own Twenty CRM instance over encrypted HTTPS. Sensitive tokens and credentials never leave your hardware-backed keychain (Apple Keychain / Android Keystore).

Team Onboarding TwentyMobile Magic
How does Single Sign-On (OAuth) work for teams? Will it create duplicate apps in Twenty CRM?

No duplicate apps are created — team onboarding is seamless and clean!

  • Shared App per Workspace: When the first user or workspace admin connects TwentyMobile to their Twenty CRM instance via SSO / Google login, its verified Client ID is published to the workspace entry, so teammates reuse that same authorized application named TwentyMobile instead of creating their own.
  • Zero-Knowledge Shared Registry: Subsequent team members entering the same workspace URL automatically discover this pre-existing Client ID. They don't have to navigate to CRM Settings, create applications, or copy-paste UUIDs. Only applications that the instance itself confirms (and that are named TwentyMobile) are accepted, and lookups are rate-limited.
  • Self-Healing on Deletion: If a CRM admin ever deletes the TwentyMobile application in Twenty CRM (Settings → Applications), the next check detects the removal and purges the stale registry record. On instances that support Dynamic Client Registration the app re-provisions itself automatically; on self-hosted instances without it, TwentyMobile simply asks for a new Client ID.
  • Zero-Knowledge Guarantee: The shared registry only stores the public hostname mapped to the public Client ID UUID (plus timestamps and the previously overwritten IDs, for auditing). It never sees, stores, or handles secrets, passwords, access tokens, refresh tokens, user accounts, or CRM data. You can disable it entirely or self-host it with --dart-define=OAUTH_REGISTRY_URL=.
